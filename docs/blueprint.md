# **App Name**: VelvetStay

## Core Features:

- Luxury Image Search: Integrated search engine that retrieves high-quality imagery of luxury villas via DuckDuckGo.
- Curated Portfolio Gallery: An elegant, grid-based visual layout to display villa results in a clean and cinematic format.
- Architectural Detail Tool: An AI-powered analysis tool that identifies key architectural styles and luxury features within searched images to provide instant stylistic context.
- Cinematic Image Lightbox: High-resolution full-screen viewer for a deep-dive inspection of villa interiors and landscaping.

## Style Guidelines:

- Primary color: Sophisticated Champagne Gold (#EBD694), conveying timeless luxury and exclusivity.
- Background color: Deep Onyx Gold (#191814), providing a high-contrast, moody atmosphere suitable for a premier portfolio look.
- Accent color: Vibrant Burnt Sienna (#D3412B), used sparingly for high-impact call-to-actions and focused interactions.
- Headline font: 'Playfair', a high-contrast serif for an elegant, editorial fashion feel. Body font: 'PT Sans', a humanist sans-serif for clarity and warmth.
- A spacious, masonry-style layout with significant whitespace to emphasize the grandeur of the visual content.
- Staggered reveal animations on search results, mimicking the opening of a high-end coffee table book.
- Thin-line, minimalist icons with a custom stroke weight to match the architectural theme.
